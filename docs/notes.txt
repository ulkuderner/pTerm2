pTerm2 Release Notes

New Features:
- pTerm2 is a standalone iPad
  terminal. It talks SSH on its own,
  so the Mac does not need to be on.
- Connect with tmux control mode
  (tmux -CC). Windows become tabs
  and panes become splits. The
  embedded tmux standard uses the
  usual prefix shortcuts, and each
  pane starts a login zsh.
- The local shell includes the Blink
  / ios_system command set, plus
  git, scp, sshfs, python3, and
  pip3.
- SSH identities are stored in the
  Keychain. Hosts remember a remote
  command, defaulting to
  tmux -CC new -A -s main.
- The shell has a theme gallery
  (Dracula, Nord, Tokyo Night,
  Catppuccin, and others). Command-D
  splits the screen and the other
  panes keep their contents at the
  new size. Click a pane to select
  it. Control-D closes that pane.
- Agents in the shell toolbar open
  Claude Code, OpenAI Codex, and
  Gemini CLI, each in its own pane.
